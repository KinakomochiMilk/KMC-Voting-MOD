# KMCVoting

**KMCVoting** is a voting system mod for Minecraft Forge 1.7.10.

It provides a Votifier-compatible server for receiving votes from external voting services.

## Requirements

- Minecraft 1.7.10
- Minecraft Forge 10.13.4.1614

## Features

- Votifier protocol support
- Vote reception using Votifier-compatible services
- Votifier V1 and V2 protocol handling

## Installation

1. Install Minecraft Forge 1.7.10.
2. Download the KMCVoting release compatible with your Minecraft version.
3. Place the mod JAR file in your Minecraft `mods` directory.
4. Configure the mod as needed and start Minecraft.
